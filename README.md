# 会議費・交際費 全数監査エージェント（非公開デモ）

サンプリングを行わず、母集団を**全件（悉皆）**判定する全数監査のワークベンチ。単一HTML＋`data.js`・完全ローカル動作・外部送信なし。

## ログイン（アプリ認証）
起動時にログイン画面が出ます。**初期値**：

| 項目 | 値 |
|---|---|
| ユーザー名 | `kansa` |
| パスワード | `Kaigihi#2026` |

- パスワードは平文で持たず **SHA-256ハッシュ**で照合（`index.html` の `AUTH_HASH`）。認証は sessionStorage 保持、ログアウトはサイドバー。
- パスワード変更：`python3 -c "import hashlib;print(hashlib.sha256('新PW'.encode()).hexdigest())"` の出力で `AUTH_HASH` を置換。
- 静的HTMLのため簡易ゲートであり、強制力は限定的（真の入室制限は認証付きホスティングが必要）。

## 見た目
`kaigihi-kosaihi-agent-demo` と同じ **Copilot Studio 風チャットUI**（3ペイン）。サイドバーのトピック一覧は非表示。

## フロー（取込を可視化 → 一括 → 介入3点）
1. **🧪 テストサンプルを読み込む** … チャットに取込ステップ（validateInputFiles）を表示：件数KPI（決裁50／仕訳48／証憑48／仕訳なし2／証憑なし2）、必須列チェック、区分内訳、先頭6件のプレビュー
2. **▶ 全数監査を実行** … 抽出→分類→グルーピング→監査チェック→仕訳/証憑突合→リスク評価まで全件を一括処理
3. **① 監査対象の確認** … 全件から誤検知を対象外化（オーバーライド）。KPI・疑義へ即時反映
4. **② 疑義の確定** … 全数チェックで検知した**全不備**を精査。指摘としない場合は取下げ（オーバーライド）
5. **③ 監査内容確認書 発行** … 確定した全疑義について確認書を生成。CSV／Excel(.xls) 出力

## 全数（悉皆）監査の考え方
- 従来のサンプリング監査（母集団から一部抽出）ではなく、**全件を機械判定**して不備を漏れなく抽出。
- KPIに「**監査済 100%（全数）**」を明示。カバレッジがサンプル率に依存しない。
- 「サンプル選定」という概念はなく、検知した不備＝すべて指摘候補。監査人は確定/取下げで関与。

## 判定ロジック（要件定義書§7・決定的）
- 6観点：決裁時期／決裁権限／**証憑突合**／勘定科目／税区分／仕訳突合
- 証憑突合：証憑なし→NG、金額差異>2%→NG、登録番号なし/OCR<0.80→要確認
- リスク加点(0-100)：時期NG+25／権限NG+25／証憑NG+20／科目NG+20／税NG+15／仕訳未突合+20
- 評価：要改善≥60／注意30-59／要確認(不備あり<30)
